# Maintaining AirTrail subpath support

- Keep `subpath` as the deployment branch. Start new work from its tip. Keep `.upstream-version` aligned with an official stable tag from `johanohly/AirTrail`.
- Merge stable tags into `subpath` and preserve their ancestry. Use `bash scripts/subpath/sync-upstream.sh` to detect and merge a release. Resolve conflicts explicitly by reviewing both upstream behavior and the existing mount changes.
- Keep internal paths prefix-free until the URL is emitted. Use SvelteKit's `resolve` for typed routes, `appPath` for dynamic paths or assets, and `cookiePath` for cookies. Use route IDs for route identity. Leave third-party URLs and externally registered callback URLs under their respective owners' control.
- Use a scheme and authority for `ORIGIN`, and a path for `BASE_PATH`. Maintain the root OAuth discovery paths required by RFC 8414 and RFC 9728. Include them in reverse-proxy checks and review CSRF/CORS exemptions when route names change.
- Keep database migrations and upload storage independent of the mount. Never reset a real database to validate sync. The deployment regression uses a disposable database, changes mounts, and reuses that database to check data compatibility.
- Review the adapter-node output layout, generated JavaScript and PWA scope after SvelteKit, Vite, or PWA dependency updates. Validate the exact compiled image at the root and a nested path.
- Run `bun install --frozen-lockfile`, `bun run test:unit`, and `docker build -f docker/Dockerfile -t airtrail-subpath:local .` followed by `bash tests/subpath/docker.sh airtrail-subpath:local` before merging. The workflow runs the Docker regression on native amd64 and arm64 runners. Review the source, build, and deployment logs in Actions if a check fails.
- Publish through the subpath workflow. It builds and tests both platform images before pushing any image tags. Keep the workflow on the repository's default branch so its schedule runs. Allow the workflow to update `subpath` without force pushes. If upstream workflow-file changes require extra permission, configure `UPSTREAM_SYNC_TOKEN` with scoped Contents and Workflows write through repository secrets.
